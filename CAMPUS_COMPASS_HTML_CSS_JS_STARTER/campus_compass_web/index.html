Connect this frontend to your existing Colab RAG code.

Start your Python API

Expose the existing embedding, retrieval and Gemini answer functions through a Flask or FastAPI endpoint. Keep your API key on the server.

STEP 02

Set the API endpoint

STEP 03

Expected ask request

Adapt the JavaScript payload to match your backend.

{
  "question": "attendance requirement",
  "institution": "ssit",
  "college_name": "",
  "category": "academic"
}
IMPORTANT

Keep institution data separate

Backend retrieval must filter documents by institution ID before searching. A dropdown in the frontend alone does not enforce data isolation. Never expose API keys in browser code.
